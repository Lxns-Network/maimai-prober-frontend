# 表述与排版示例

以下只演示写法，不代表待发布功能、实际配额或当前接口契约。写入前用本次变更核实事实。

## 玩家与 API 受众

| 原始描述                                   | 对外表达                                                                      |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| 缩减离屏合成开销                           | 有体感改善证据时写“优化谱面预览的渲染性能，提升动画流畅度”；否则不写          |
| 解析个人主页异常导致服务内部错误           | 修复特定情况下同步个人数据可能失败的问题                                      |
| 新增滑块，范围、步长、默认值以及本地持久化 | 新增「星星延迟」设置                                                          |
| 成绩接口新增可选字段                       | `Score` 结构体中新增 `last_played_time` 字段，用于获取谱面的最后游玩时间      |
| OAuth 回调地址配额改变                     | OAuth 应用现在最多可以登记 10 个回调地址                                      |
| 未知客户端的 HTTP 响应变化                 | OAuth 授权时若使用的 `client_id` 已失效，现在返回 `404`，客户端可据此重新注册 |

不要把“限制创建应用数”的提交翻译成“限制回调地址数”；即使数字相同，约束对象也不同。后端变更需核对处理逻辑、公开结构与接口文档。

## 合并边界

- 同一新页面的实现、样式调整及发布前修复：合为该页面最终能力。
- 同一区域的多项能力：可用父条目与精炼子条目。
- API 压缩支持与开发者页面交流群链接：分开，不用“以及”拼接。
- 旧浏览器页面故障与会话过期提示缺失：问题不同，应分别表达。
- 已发布功能的新故障修复：可独立列出，不因日期相同就折叠进旧成果。

## 破坏性变动

在同日普通条目下方单列，替代方式须与实际接口一致：

```markdown
### ⚠ 破坏性变动

以下变动将会影响开发者，请检查你的代码是否受到影响：

- `Score` 结构体中删除 `old_field` 字段
  > 请改用 `replacement_field` 字段获取对应信息。
```

存在需用户操作的提醒时可沿用日志已有的 `::: info 提示` 容器；接口迁移说明可用引用块。无需为普通文字改动新增容器。
