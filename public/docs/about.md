# 关于

---

[落雪咖啡屋 maimai DX 查分器](/)是一个简单的舞萌 DX & 中二节奏国服查分器，玩家可以查看并管理自己的成绩，同时也有公共的 API 接口供开发者获取玩家的成绩数据。
